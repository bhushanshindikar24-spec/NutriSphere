|---|---|---|---|
| **Programming Language** | Java | 17 (LTS) | Backend runtime execution |

| **Security Framework** | Spring Security | 6.3.3 | Authentication & authorization filter chain |
| **Token Specification** | JJWT (io.jsonwebtoken) | 0.12.6 | JWT token signing, verification & parsing |

| **Frontend Framework** | React | 19.0.0 | Client-side reactive UI rendering |
| **Build Tool & Dev Server** | Vite | 8.3.2 | Fast bundle compiling and HMR |
| **Client Routing** | React Router DOM | 6.22.3 | Declarative client-side routing & navigation |
| **HTTP Client** | Axios | 1.6.8 | Promise-based HTTP client with interceptors |
| **Icons & Visuals** | Lucide React | 0.359.0 | Clinical and dashboard iconography |
| **Styling** | Vanilla CSS | CSS3 | Custom responsive clinical design system |
| **Containerization** | Docker & Docker Compose | 3.8 Spec | Production packaging and container orchestration |
| **Reverse Proxy** | Nginx | Alpine 1.25 | Production static serving and API reverse proxy |
