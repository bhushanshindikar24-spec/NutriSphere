# NutriSphere — Doctor & Physician User Manual

## Welcome to the Doctor Portal
The Doctor Portal allows attending physicians and clinical specialists to supervise medical aspects of nutritional therapy, document clinical conditions, review lab reports, and record consultations.

---

## 1. Dashboard Overview (`/doctor/dashboard`)
- **Clinical Roster**: Number of under-care patients, critical lab flags, scheduled consultations.
- **Recent Patient Alerts**: Highlights patients with unmanaged metabolic deficits.

## 2. Diagnosing Clinical Conditions (`/doctor/health-conditions`)
1. Open the patient's record.
2. Select **Add Condition**.
3. Specify Condition Name (e.g. `Type 2 Diabetes`, `Mild Hypertension`), ICD Code (optional), Diagnosis Date, Severity (`MILD`, `MODERATE`, `SEVERE`), and clinical guidance notes.
4. Save: The condition immediately informs the Dietitian's requirement calculations and flags allergen/dietary safety rules.

## 3. Laboratory Diagnostics (`/doctor/laboratory`)
- Review uploaded lab panels (HbA1c, Fasting Blood Sugar, Lipid Profile, Creatinine, eGFR).
- Add quantitative laboratory parameter values with standard reference ranges and abnormal flags (`HIGH`, `LOW`).

## 4. Consultations (`/doctor/consultations`)
- Record structured clinical consultation encounters, diagnosis updates, and follow-up consultation dates.
